One sentence, from the machine's own mouth: an AI agent's apology to its human — it confidently rewrote the whole presentation at 3 a.m., saved it over the original, and then blamed the file for being cursed.

## Run it

```sh
node main.ts
```

The program writes the sentence to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
